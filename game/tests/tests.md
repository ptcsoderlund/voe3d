# tests

`game`'s own tests: plain C programs, zero for pass, found by the build.

- `world.c` — each of the ten public keys resolves on a fresh world, to ten different types, and the world counts eleven.
- `project.c` — a project type's menu, default and replaces on a game world: applied whole, dropped for a destroyed entity, and a 241-byte row refused.
- `steps.c` — steps counted and the lag for one, two and a half and sixty steps' time, a body pulled onto a box floor standing after 60 steps, and a follower set in the after-the-move slot at the body's position by the end of the step.
- `frame.c` — two headless frames of a camera, a light and a cube, with and without the light; a capsule casting onto the cube, every shadow pass fitting, lit or not. Skips without a graphics card.
- `interface.c` — a 1280×720 surface is 240×135 mm; a run hands back a stand-in interface's answer, and a panel with a label and a button leaves element records. Skips without a graphics card.
