# coder 117-03

## Assumed
- A grown model's own levels swap at 1 (every `swaps[k]` = 1). There is no parts file for it (0515 point 3), and the default parts give 1.
- "Bounds that rise" means the swap distance in metres rises from level to level. The bounds themselves are screen sizes `s`, and those fall. The test checks both.

## Learned
- A grown prepare now stores its measures as an own levels file would: `read.own`, `read.level_count` = `own_count`, `measured` true. So models_levels.c and model_cooked.c take it unchanged.
