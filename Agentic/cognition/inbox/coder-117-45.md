# coder 117-45

## Learned
- In memory a look's `share` has no stand-in default the way `size` and `blend_height` do: 0 is a real share. A look zeroed or built by compound literal therefore writes `share<g>_<j>=0` unless `.share = 1` is set. `voe_assets_landscape_look_default()` sets it to 1.

## Assumed
- The file's spelling is decided by one walk of `[Foliage]`. Any key `kind<digit>…` makes the file old, and any key `glb<digit>…` makes it new. Both in one file is MALFORMED under the lenient read and the strict read alike.
- The old spelling has no `share<k>` key. The strict read refuses one, and the lenient read ignores it.
- `seed<g>` is written after all of its group's glb lines.
- A seed in the old spelling has the same range as a group seed, 0–15. It is clamped by the lenient read and refused by the strict read.
