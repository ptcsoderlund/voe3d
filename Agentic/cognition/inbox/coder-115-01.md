# coder 115-01

## Assumed
- A key the lenient landscape reader stops before is "a key no section takes", so strict refuses it. That covers `layer2` or `kind2` after a gap, a look key or paint row of a kind or layer past the count, and `[Paint]` rows in a file with no layers.
- A section the format does not have is refused even when it is empty, and the refusal names the section's own line.

## Surprised
- Done when says the ctest output "includes the five new tests". The testing harness prints no test names, so ctest shows only `assets/material` and `assets/landscape`. With `-V`, the new tests show up only through their refusal lines on stderr.
