# coder 115-05

## Assumed
- The watch walks the project itself, with assets_walk.c's extension and skipped-folder lists copied, since assets_walk's walk is static and the card names only the two new files; a new kind must now be added in both lists.
- Settling takes the change's stamp as known whether or not it was taken, so "keep mine" and a refused file are not found again each second; only the bytes wait on `taken`.
- A change whose path the editor writes while it is held is marked `written`, and its settle leaves the known stamp and bytes alone, so the editor's own later write is never seen as outside.
- A new `.landscape` is noted without being read or strict-read, and a changed file that will not read is not a change and is tried again next look.
- A NULL folder counts as a folder unlike the last: everything known is forgotten.
