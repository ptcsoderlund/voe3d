# coder 116-12

## Assumed
- `cells`' least is the literal 4: landscape.h has no CELLS_MIN, and the reader itself writes 4.
- `layer<N>`, `kind<K>` and `grow<L>_<K>` have default "" although none is required: absent ends the list or grows nothing, and no value spelled in the file means "absent" (`grow=0` is refused). The row type's "" reads as "required"; the `says` line says otherwise for these.
- Paint rows carry 0 to 255, refused, as the range of each weight; heights and copies, many numbers of mixed meaning, carry no range.

## Surprised
- The card lists `vary, turn, tilt, shadow, blend, blendheight` bare; in the file each is per kind, so the rows are `vary<K>` and so on.
