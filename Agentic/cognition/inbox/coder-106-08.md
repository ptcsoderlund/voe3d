# coder 106-08

## Learned
- A landscape row is never chosen through a LOD memory (draw_models.c and draw_system.c skip it before `voe_3d_lods_kept_choose`), so only non-landscape model rows and foliage copies get keys.
- A single-level model row is still remembered in the memory; `find` is true for it after a frame.
