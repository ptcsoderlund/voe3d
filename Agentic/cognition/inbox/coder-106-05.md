# coder 106-05

## Learned
- `voe_3d_model_level_choice.shown` is now in [0, 1], not (0, 1]: a kept swap answers 0 on its own frame (elapsed 0 ÷ 0.25); the stateless `_choose` still never answers below its band floor.
- `voe_3d_model_level` no longer asserts the share; it is `_level_at(_level_size(...))`, same level as before.

## Assumed
- `_choose` sets `from` = `level` − 1 only while in its band (shown < 1), else `from` = `level`, matching "`from` = `level` when settled"; the card's bare "`level` − 1" would underflow at level 0.
- A kept LOD or from at or past the model's `level_count` (a reload, or two keys colliding across models) is treated as first sight, so a draw never indexes a level the entry lacks.
- `_find` answers last frame's slot at last frame's clock (the choice as it stood then), this frame's at this frame's.
- The swap moment is kept as a double, making a slot 24 bytes and a memory 12 MiB; `_begin` asserts the clock never goes back.

## Surprised
- The top-level `3d/3d.md` lists some headers too, but checks only require `3d/include/3d/3d.md`; the new header is listed only there, as the card says.
