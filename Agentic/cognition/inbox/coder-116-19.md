# coder 116-19

## Assumed
- "After a code swap succeeds" taken as any built refresh whose swap did not fail (bytes equal included), so a Refresh press rewrites Docs as 0511 point 3 asks even when the library is unchanged; the Refresh command itself does not set `docs_due`.

## Surprised
- A Refresh in a project with no `.c` in `Code/`, or one whose build fails, does not rewrite Docs: only open, first Save and a built refresh do.
