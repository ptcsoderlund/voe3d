# coder 106-06

## Learned
- A swap's first frame has `shown` 0 (lods_kept sets the swap moment to that frame's clock), and a dither of 0 draws whole: drawing `level` at dither 0 there would show the new LOD whole for one frame, then mostly the old one. Model rows now draw `from` alone, whole, on that frame and start the dissolve on the next.
- The shadows call chooses before the camera pass, so a row's memory slot is written by its first cascade draw; the camera's later choose gets the same answer for that frame.

## Assumed
- draw_levels checks "level 1 and level 0" on the frame after the swap (0.1 s in), not on the swap frame itself, because the swap frame draws the old LOD alone (see above).
- `frame.lods = NULL` is set in draw_system.c's _frame, which the card did not name; the frame there is not zero-initialised, so "_frame leaves it NULL" needs that line.

## Surprised
- The card's test step "moved past level 1's bound one frame later it draws level 1 and level 0" cannot hold on the swap frame itself with shown 0 meaning "level on no pixel".
