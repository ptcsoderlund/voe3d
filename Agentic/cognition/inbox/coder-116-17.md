# coder 116-17

## Assumed
- "When `Code/` exists but no library is built" is read as `voe_editor_game_tree_has_code`: `Code/` lists a `.c` file. A `Code/` with no `.c` registers nothing, so nothing goes unchecked.
- A library that is built but will not load is reported as one line with its reason, followed by "the project's own components were not checked". It is not counted as a refused file.

## Surprised
- The card says `return voe_editor_check(options.folder);`, but `options.folder` lives in main's arena on Windows. So main.c keeps the exit code, destroys the arena after the check, then returns the code.
