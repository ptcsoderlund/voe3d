# coder 115-12

## Assumed
- A held change the editor has written over since it was found (`written`) is settled untaken, not taken: the disk now holds the editor's version, so taking the outside one would show what disk no longer says.
- Taking a closed prefab via voe_editor_file_take resets the world, so the selection is noted by authored id and re-found around it, as a scene take does.
- After a `.material` is taken, voe_editor_scene_material_refresh is called so the Inspector's open material shows the new values.
- The safety net compares only materials (written text of both) and project.voe3d (scene path and window); `.parts` has no table models.h exposes, so a `.parts` with the same content still goes through voe_editor_file_take and records a step.
- voe_editor_undo_settle(..., false) is called before a scene take so an empty line records the before state and the take is one step Ctrl+Z can undo.
