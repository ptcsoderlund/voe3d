# coder 108-06

## Assumed
- A kind's box and its title choice are both keyed `kind` with index k; ui keys a node under its parent, so the box (in Foliage's body) and the choice (in the box's header row) do not collide.
- A kind dropped on the add row clears its fold after voe_editor_models_kind_set, with "added" decided from the grid's kind count before the set; the landscape path is the model row's, as the draw names it.

## Learned
- A folded kind's `kind_looks[k]` is not refreshed (only kind_slider_draw copies it), which is safe because nothing reads it while the box's controls are VOE_UI_NODE_NONE.
