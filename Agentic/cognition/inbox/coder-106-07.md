# coder 106-07

## Learned
- On a swap's first frame `shown` is exactly 0, and a dither of 0 draws whole. So a foliage copy gives its incoming LOD a dither of FLT_MIN. That is below the pattern's least threshold of 1/32, so it keeps no pixel, yet it stays an instance and casts, because shadow passes read no dither. Model rows instead skip the incoming LOD on that frame; their shadow comes from a separate draw of the kept LOD.
- Foliage now chooses its LOD after its tier. Only seen and cast copies write the memory. Unseen copies use voe_3d_model_level whole.

## Assumed
- A shadowless kind's copy that is not seen is left out before its LOD is chosen, so it touches no memory even in the cast tier. Nothing draws it, and first sight on its next view is what 0501 point 3 says anyway.
- `voe_3d_frame.lods`'s comment in draw_system.h now names foliage copies as well as model rows. That file was the card's, but this line was not.

## Surprised
- None of the `3d/include/3d/3d.md` entries mentioned the band, so none needed changing. The band was in `3d/tests/tests.md`'s `model_levels.c` entry, in `draw_system.h`'s `rest` field comment and in its view counts comment, and all three are fixed.
- The card's test asks for level 1 groups on the swap's first frame. That only holds if the incoming LOD is gathered at `shown` 0, which is what forced the FLT_MIN dither.
