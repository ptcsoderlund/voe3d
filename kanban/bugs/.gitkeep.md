# bugs

**An unordered inbox. Anyone may report here** — coders, the principal, end users.
One report per file, `NNN-slug.md`, with any screenshots beside it under the same
number. Numbers are arrival order and mean nothing else: **the order things get
fixed lives in `todo/`**, not here.

**Nothing is ever claimed from this folder.** A report is a finding; a decided fix
is a card in `todo/` that names the report.

**Reporting costs almost nothing** — what happened in your own words, who saw it and
when, and anything you already have. An agent grows the file into a full
investigation later, in place, and never rewrites what you wrote.

`status:` is `new` → `investigated` → `card NNN` → `closed`, plus `not a bug`.

**Only reports still awaiting a decision live here.** Once a report becomes work —
cards exist in `todo/` naming it — or is finished without work, it moves to
`archive/` beside this file, evidence and all. So the length of this folder is the
number of things waiting on the tech lead or the principal.

**The loop:** anyone reports here → the tech lead decides → cards in `todo/` naming
the report, and the report is archived in the same act → `todo/` → `review/` →
`complete/`.

Rules: ADR-0108, ADR-0109, ADR-0110. Worked example:
`001-element-surface-blank-on-windows.md`.
