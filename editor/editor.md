# editor

The program a person opens to author a scene, or runs with `--capture` to
write one frame to a PNG with no window. A leaf like `dev`: it names what it
needs and nothing names it (ADR-0121). It links `audio` so a project library
that plays sounds loads. A gap in an engine folder is a card there, never a
reach-around from here.

- `src` — the implementation: the loop, the project and its session, undo,
  the themes, the top bar, the browser, Preferences, the dock and the three
  panels; each file is listed on `src/src.md`.
