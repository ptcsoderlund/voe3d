# coin_game

The coin game of 0186: collect the coins before the score runs out. The sponsor builds its
levels in the editor; agents write its code (0251).

- `main.scene` — the level, the sponsor's: a camera and a sun to build on.
- `pickup.wav` — the starter pickup sound, shipped beside the game (0266 point 3); each coin's Inspector can swap it.
- `Code` — the game's components and systems; each file is listed on `Code/Code.md`.
